# Fonctionnalité template: proposal

Workspace-level Linear issue template « Fonctionnalité ». Applies the Type label
**Fonctionnalité**. Title prefix: none. Semantics and the test that decides
this type: [`../../references/ticket-types.md`](../../references/ticket-types.md).
Starts from the existing Fonctionnalité template; adds the user story, acceptance criteria and scope.

```markdown
## En clair, avec un exemple

<Ce que l'utilisateur pourra faire, et un cas concret. Ex. : « Une invitation envoyée depuis l'agenda s'ouvre comme une invitation dans la messagerie du client. »>

## Besoin

En tant que <rôle>, je peux <action>, afin de <bénéfice>.

## Critères d'acceptation

* [ ] …
* [ ] …

## Hors périmètre

Ce que cette fonctionnalité ne fait pas.

## Spécification

Lien vers la spec et date de sa version actuelle.

## Design requis

Oui ou non. Si oui, pour le JJ/MM.

## Découpage tech

Rempli par les devs : les Tâches techniques liées, en sous-issues.

## Preuve attendue

Ce qu'on montrera une fois livré : les tickets Preuve du milestone.
```
